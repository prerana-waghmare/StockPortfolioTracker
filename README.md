# 📈 Stock Portfolio Tracker

Hey! 👋 This is a lightweight, console-based Java application designed to help you track your stock investments, monitor live portfolio values, and calculate your profits or losses in real-time. 

I built this to keep things simple, clean, and robust—complete with input validation so the program doesn't crash if you accidentally type a word instead of a number.

---

## ✨ Features

- **Add Stocks:** Easily input stock names, quantities, purchase prices, and current market prices (pre-configured with ₹ currency).
- **View Portfolio:** Displays a clean, neatly formatted tabular summary of all your holdings.
- **Investment Summary:** Instantly calculates the total capital you've invested.
- **Profit & Loss Tracking:** Automatically tracks overall and per-stock returns, letting you know if your portfolio is in profit, at a loss, or breaking even.
- **Robust Error Handling:** Built-in safeguards prevent infinite loops and crashes from invalid text inputs or negative numbers.
